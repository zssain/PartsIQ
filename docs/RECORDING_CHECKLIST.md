# PartsIQ — recording checklist

Use this before, during and after recording a demo from [docs/DEMO_SCRIPT.md](DEMO_SCRIPT.md).
No video exists yet; this checklist is how one gets made honestly.

## Before recording

- [ ] Confirm the environment uses **synthetic data only** — no real customer data, credentials
      or secrets anywhere on screen (check the address bar, dev tools, and any tokens).
- [ ] Run the **demo reset** so you start from a clean, isolated session.
- [ ] Decide the script: the 3-minute essentials or the 8-minute full tour.
- [ ] Set browser zoom to 100% for the main pass; plan one 200% pass to show accessibility.
- [ ] Prepare to show both English and Arabic (RTL).

## During recording

- [ ] Happy path: machine identified, compatible-only parts, bilingual draft.
- [ ] Missing serial: a clarifying question, not a guess.
- [ ] Incompatibility: refusal **with evidence** (open the cited page).
- [ ] Stock split: fulfilment across warehouses; shortfall shown as a back-order.
- [ ] Human review: verification results, match score (not a probability), **approve**.
- [ ] **Failure handling**: trigger a recoverable error; show a typed message and preserved input.
- [ ] **Reset**: run the demo reset and show prior session data is gone (isolation).
- [ ] Keep all secrets off screen throughout.

## After recording

- [ ] Add captions per the script's caption track (name the guarantee shown in each step).
- [ ] Re-watch once to confirm no secret or real datum appears.
- [ ] **Verify every link works** (demo URL, repo, this guide) before sending to recruiters.
- [ ] Only now add the recording link to the README/recruiter guide — do not claim a video
      exists until it is recorded and its link verified.
