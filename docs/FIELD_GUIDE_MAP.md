# Fifteen field-guide habits

| Habit | Concrete kit implementation |
|---|---|
| 1 Handover | HANDOVER.md read first and updated after every prompt |
| 2 Decisions | DECISIONS.md records reason,consequence and source approval |
| 3 Explicit comments | Prompt logic asks for callers,assumptions and intent |
| 4 Flow | FLOW.md binds entries to prompt-owned functions |
| 5 Feature/bug traces | 69 feature files and completed-example bug template |
| 6 Architecture | Eight questions answered in ARCHITECTURE.md |
| 7 Constraints | Numbered immutable boundaries and approved exceptions |
| 8 Test checklist | Named paths,commands and expected outcomes |
| 9 Rollback | Pre-task tags,compensating migration and release rollback |
| 10 Read diff | Required before marking an implementation complete |
| 11 Ask why | PLAN CHECK describes reasoning before edits |
| 12 Small requests | One implementation prompt and commit at a time |
| 13 Handoff | Five-line session summary |
| 14 Context version | Actual model/version if exposed; otherwise not exposed |
| 15 Mental model | Agent explains change in plain English; recruiter guide rehearses architecture |

The supplied guide is preserved in references/AI-Collaboration-Field-Guide.pdf. Its approval guidance does not override the owner's already-granted authorization for this sequence.
